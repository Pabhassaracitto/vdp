# Offline UI font subsets

These files are generated by `tool/subset_fonts.py` from the corresponding
Google Fonts Noto families. Only glyphs present in the bundled ARB resources
(and a shared Pāḷi character set) are retained.

Families used:

- Noto Sans
- Noto Sans Arabic, Bengali, Devanagari, Myanmar, Sinhala, Khmer, Lao, Tamil,
  Telugu and Thai
- Noto Serif Tibetan
- Noto Sans SC, TC, JP and KR

All source fonts are licensed under the SIL Open Font License 1.1. The license
is included as `OFL.txt`. The generated fonts must be regenerated whenever a
translation introduces new characters.
